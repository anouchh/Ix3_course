## Файлы

### `model.pkl`

Сериализованная финальная модель, готовая к использованию в сервисе.

- **Алгоритм:** Pipeline (StandardScaler + LogisticRegression)
- **Библиотека:** scikit-learn, сериализация через joblib
- **Обучена на:** `data/WA_Fn-UseC_HR-Employee-Attrition.csv`, train-часть (80%, 1176 строк)
- **Параметры модели:** `class_weight='balanced'`, `max_iter=1000`, `random_state=42`

**Метрики на тестовой выборке (20%, 294 строки):**

| Метрика | Значение |
|---------|----------|
| ROC-AUC | 0.807 |
| Recall (уволился) | 0.77 |
| Precision (уволился) | 0.27 |
| F1 (уволился) | 0.38 |

**Как воспроизвести обучение:** запустить ноутбук `notebooks/01_eda.ipynb` полностью —
модель будет переобучена и сохранена заново в этот же файл.
