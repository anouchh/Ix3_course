# configs/

В этой папке хранятся конфигурационные файлы проекта.

---

## Файлы

### `.env.example`

Шаблон переменных окружения. Скопируй в `.env` и при необходимости измени значения:

```bash
cp configs/.env.example .env
```

`.env` добавлен в `.gitignore` и **не попадает в репозиторий**.

**Доступные переменные:**

| Переменная | Значение по умолчанию | Описание |
|------------|----------------------|----------|
| `APP_HOST` | `0.0.0.0` | Адрес, на котором запускается сервис |
| `APP_PORT` | `8000` | Порт сервиса |
| `LOG_LEVEL` | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`) |
| `MODEL_PATH` | `artifacts/model.pkl` | Путь к файлу модели относительно корня проекта |

Все переменные читаются в `src/service/app.py` через `os.getenv()`.
