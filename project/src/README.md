# src/

В этой папке находится основной код проекта.

---

## Структура

```
README.md                  — описание источника данных и признаков
data/
    __init__.py
    preprocessor.py        — предобработка входных данных (кодирование категориальных признаков)
models/
    __init__.py
    predictor.py           — загрузка модели из artifacts/ и выполнение предсказания
service/
    __init__.py
    app.py                 — FastAPI приложение
```

---

## Модули

### `preprocessor.py`

Принимает словарь с признаками сотрудника и возвращает `DataFrame`, готовый для подачи в модель.

Ключевая функция: `preprocess_input(data: dict) -> pd.DataFrame`

Логика:
- категориальные признаки кодируются по фиксированным маппингам (не LabelEncoder)
- фиксированные маппинги гарантируют одинаковую кодировку при обучении и инференсе

---

### `models/predictor.py`

Загружает модель из `artifacts/model.pkl` и выполняет предсказание.

Класс: `AttritionPredictor`
- `__init__` — загружает модель один раз при старте сервиса
- `predict(df) -> dict` — возвращает `attrition_probability` и `risk_level`

Уровни риска:
- `low` — вероятность < 0.35
- `medium` — вероятность 0.35–0.60
- `high` — вероятность > 0.60

---

### `service/app.py`

FastAPI приложение с двумя эндпоинтами:

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/health` | Проверка работоспособности |
| POST | `/predict` | Предсказание по профилю сотрудника |

Входные данные валидируются через Pydantic-модель `EmployeeFeatures`.
Каждый запрос и результат логируются через стандартный `logging`.
